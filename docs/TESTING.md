# 测试与验收

## 自动化

在 Windows 上运行 `scripts/build.ps1`。xUnit 测试不发送真实鼠标或键盘输入，适合 CI。

- 配置数值边界、损坏 XML、外部实体拒绝。
- 配置读写与原子替换、保存失败保留旧文件并清理临时文件。
- 限定轮数、无限模式、重复启动、停止后晚到计数和重新启动。
- 三种按键的单/双击 down/up 序列，以及运行架构对应的 Win32 INPUT 内存布局。
- 无热键消息时的 F10 状态检测、跨线程短按捕获、松键后保留请求、按住停止键禁止重新开始。

CI 在 Windows x64、x86 测试宿主下运行测试；常规编译将警告视为错误。

## 人工检查清单

请使用专门的无副作用点击计数窗口，不要在业务系统上测试。

- [ ] Windows 10 / 11，100% / 150% / 200% 缩放：全部控件可见。
- [ ] 将焦点切到其他窗口，F9 开始、F10 停止。
- [ ] v1.0.1：同时按 Ctrl/Alt/Shift 与 F10，备用按键检测停止；核对状态栏触发来源。
- [ ] 默认启动延迟内按 F10，确认不产生点击。
- [ ] 单击设 3 轮，目标准确收到 3 次；双击设 3 轮，收到 6 次。
- [ ] 无限模式运行后按 F10，之后没有新的点击。
- [ ] 20 ms 和长间隔下停止均可响应。
- [ ] 左/右/中键各自正确；手动移动鼠标后点击新位置，程序不将鼠标移回旧位置。
- [ ] 含 FixedPosition=true 的旧配置仍可读取，但不会出现坐标控件或移动鼠标。
- [ ] F10 被其他程序注册时无法启动；F9 被占用时按钮仍可启动。
- [ ] 运行时关闭窗口会停止，关闭后快捷键可被再次注册。
- [ ] 更高权限窗口拒绝输入时停止并提示；锁屏后不继续误点。
- [ ] 重启保持设置，损坏配置显示默认值，文件只读时能提示保存失败。

## 首次发布验证范围

本地已进行可视化布局检查及消息级开始/停止检查。自动化桌面未接收合成键盘输入，并拒绝 SetCursorPos，因此不能将消息级检查当作真实键鼠端到端通过。完整人工矩阵仍待实际桌面验收；本项目在 README 和发行说明中保留该限制。
